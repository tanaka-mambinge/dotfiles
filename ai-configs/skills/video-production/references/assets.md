# Icons, logos, and vector assets

- Do not create custom SVGs, icons, or replacement brand marks. Use an established icon pack such as Tabler or Phosphor when an icon helps. For brand marks, use an appropriate supplied or official logo asset; [theSVG](https://thesvg.org/) is a useful brand icon directory. Follow the brand's usage guidance when available.
- If a needed asset cannot be found in an established pack or official source, ask the user to find/provide one or choose whether to have one generated with an appropriate tool. Do not draw the SVG yourself.
- Preserve logo proportions and use icons only when they clarify the visual. Do not add decorative icon grids to fill space.
